DS-STAR / Design proposal

A foundation before a facelift

The current UI already has a palette, a brand accent, and a component library — what it's missing is a type scale and a spacing scale to hang them on, which is why 66 one-off pixel values have crept into the codebase and every screen feels slightly uncalibrated against the next. This proposes both, plus a warmer neutral ground and a wider, more deliberate range for the existing crimson brand color — not a new palette, a fuller use of the one already chosen.
